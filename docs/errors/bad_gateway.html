Bad gateway

An HTTP error that errdown classifies as bad_gateway.

true

502

What you should do

Wait 5 seconds, then retry with exponential backoff. Stop after a few attempts and report the error if it persists.

Names may carry a source prefix (for example nginx_bad_gateway); they mean the same thing, produced by that server.
